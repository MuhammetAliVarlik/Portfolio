How I work

Three principles behind every project

  1. 01

    I do not trust model output blindly

    Numeric grounding checks each figure in a report. A Cohen's kappa test checks the LLM judge. See the guardrails.

  2. 02

    I look for silent failures

    I found a judge that scored empty strings, embeddings that ignored films and a prototype that leaked future data. I fixed each one before it changed a result. See the leakage fix.

  3. 03

    I ship responsibly

    I use read-only tools, CSP and OIDC deployments, and I document the limits of each project. I kept a ready release on hold for a KVKK data protection review. See the correctness pass.
