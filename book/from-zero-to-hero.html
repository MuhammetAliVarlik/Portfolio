Why it existsNeden var

Most DS/AI material is fragmented: one course covers pandas, another a single algorithm, a bootcamp covers "AI" but skips the SQL and infrastructure underneath. This repository is one ordered pipeline — Python → statistics → SQL → NumPy/Pandas → ML → deep learning → LLM engineering → MLOps → GPU programming — with every lesson tagged from beginner to expert.

Çoğu Veri Bilimi/AI materyali parçalı: bir kurs pandas'ı, bir diğeri tek bir algoritmayı anlatıyor; bir bootcamp "AI"yi anlatıp altındaki SQL ve altyapıyı atlıyor. Bu repo tek ve sıralı bir pipeline — Python → istatistik → SQL → NumPy/Pandas → ML → deep learning → LLM mühendisliği → MLOps → GPU programlama — ve her ders başlangıçtan uzmana kadar etiketli.

Role-based pathsRol bazlı yollar

The same 27 sections, different routes: Data Analyst, Data Scientist, Data Engineer, AI/ML Engineer, LLM/GenAI Engineer and MLOps/Platform Engineer.

Aynı 27 bölüm, farklı rotalar: Veri Analisti, Veri Bilimci, Veri Mühendisi, AI/ML Mühendisi, LLM/GenAI Mühendisi ve MLOps/Platform Mühendisi.

How it was made — stated openly:Nasıl yapıldı — açıkça belirtilmiş:

Lesson content was generated with AI assistance and then reviewed, curated and structured by me. I use it as my own study material and share it free, with no paywall or sign-up.

Ders içerikleri AI desteğiyle üretildi, ardından benim tarafımdan gözden geçirildi, seçildi ve yapılandırıldı. Kendi çalışma materyalim olarak kullanıyorum ve ödeme duvarı veya kayıt olmadan ücretsiz paylaşıyorum.
